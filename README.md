# API Kalender Akademik Kabupaten Bandung Barat

Data **Kalender Pendidikan Dinas Pendidikan Kabupaten Bandung Barat (KBB)** dalam bentuk JSON statis.

---

## Endpoint

Base URL:

```
https://raw.githubusercontent.com/arv-fazriansyah/api-kalender-akademik-kabupaten-bandung-barat/main/data/
```

| File | Keterangan |
| --- | --- |
| `kalender.json` | Indeks semua tahun ajaran yang tersedia |
| `2025-2026.json` | Kalender tahun ajaran 2025/2026 |
| `2026-2027.json` | Kalender tahun ajaran 2026/2027 (lengkap) |

Contoh:

```bash
curl https://raw.githubusercontent.com/arv-fazriansyah/api-kalender-akademik-kabupaten-bandung-barat/main/data/kalender.json
```
